# Complete feature catalog

Status: every product capability is Planned. Descriptions and acceptance criteria
are proposals; nothing in this catalog asserts implementation. Priorities use P0
Critical, P1 High, P2 Medium and P3 Low. Phases are release-gated, not dates.

The original [founder brief](founder-brief.md) is preserved for traceability.
Each row has a stable ID, a capability description, priority/phase, dependencies,
user story and minimum acceptance criterion. Cross-cutting security, localization
and testing requirements apply to every row. Module dependencies are baseline
prerequisites, not circular feature scheduling; Phase 1 detail is in the backlog.
